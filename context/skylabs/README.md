- `CONTENT_GUIDELINES.md` — brand voice, content principles and factual standards (verbatim from the full pack).

## Agent instructions

Read `SKYLABS.md` and `CONTENT_GUIDELINES.md` first, then `products/LOGIX.md` before any Logix work. Treat these files as context, not permission to invent facts. Newer instructions from the team override this pack.

Do not invent capabilities, customers, metrics, deployments, partnerships or outcomes. Distinguish live, in-development, planned and exploratory work. Keep client and commercial details confidential unless explicitly approved.

Context reflects information shared up to 8 November 2026. Verify time-sensitive details before publication.
