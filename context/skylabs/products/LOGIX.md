These are content territories, not a confirmed Logix feature list.

## Useful distinction for content

A fleet can generate data without that data automatically becoming useful operational intelligence.

- A GPS point indicates a location at a moment; it does not by itself guarantee an accurate ETA.
- A dashboard can report an exception; it does not automatically explain the cause or determine the right action.
- Multiple systems can contain useful information while creating integration, consistency and context challenges.

These observations can support educational content. Do not claim Logix already solves them unless the capability has been demonstrated and approved for public description.

## Confidentiality and accuracy

Never disclose without explicit approval:
- The client's name or logo in marketing material.
- Contract amount or commercial terms.
- Client data, fleet information, screenshots or workflows.
- Product architecture, security details or customer-specific requirements.
- Unreleased capabilities or delivery commitments.

Before making a Logix claim, establish whether it is live, in development, planned or exploratory; whether it has been tested; whether it can be demonstrated; and whether it is approved for public release. If unclear, use problem-led educational framing.
